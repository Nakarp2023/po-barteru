# ПО БАРТЕРУ — следующий этап

## Что уже работает
- Адаптивный мобильный веб-прототип.
- Поиск по объявлениям и фильтр по категориям.
- Добавление объявления в текущем браузере.
- Избранное.
- Объявления и избранное сохраняются в localStorage на этом устройстве и в этом браузере.

## Важное ограничение
Это пока не серверная база: объявления не видны другим пользователям и не синхронизируются между устройствами. Демонстрационные объявления — примеры интерфейса, не реальные предложения.

## Подключение серверной базы
1. Создать проект Supabase.
2. В SQL Editor выполнить файл `supabase/schema.sql`.
3. В настройках проекта взять Project URL и publishable/anon key.
4. Подключить клиент Supabase в интерфейсе и настроить вход по email/телефону.
5. Перед публичным запуском проверить RLS-политики и модерацию.

Никогда не добавлять `service_role` key в браузерный код.
