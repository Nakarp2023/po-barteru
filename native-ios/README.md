# ПО БАРТЕРУ — нативная iOS-оболочка

Этот каталог добавляет нативное приложение iOS поверх существующего сайта. Веб-сайт и Supabase остаются источником бизнес-логики и данных; платежные статусы и записи базы не изменяются.

## Что делает оболочка
- Загружает https://po-barteru.onrender.com в WKWebView.
- Скрывает веб-панель навигации только внутри нативного приложения.
- Показывает нативную SwiftUI-панель из пяти разделов.
- На iOS 26+ использует системный Liquid Glass через SwiftUI `.glassEffect`; на iOS 17–25 использует системный материал как fallback.
- Нажатие нативного раздела передаётся существующей навигации сайта через JavaScript.

## Сборка
Требуется Mac с Xcode 26+ для полноценной проверки Liquid Glass и подписи приложения. Установите XcodeGen, откройте Terminal в каталоге `native-ios` и выполните:

```sh
brew install xcodegen
xcodegen generate
open PoBarteruNative.xcodeproj
```

В Xcode выберите команду Signing & Capabilities, укажите свою Apple Developer Team и соберите приложение на iPhone или в архив для TestFlight.

## Важные ограничения
- Это первый нативный shell, который подключает веб-приложение удалённо; интернет нужен для загрузки сайта.
- Нативная панель использует настоящий системный материал Liquid Glass на iOS 26+, но это не повторяет прежнюю кастомную лупу, которая следует за пальцем. Она заменена на нативную систему выбора вкладок. Если лупу нужно оставить, её следует отдельно реализовать как кастомный SwiftUI glass control.
- Этот репозиторий не содержит сертификатов подписи. IPA нельзя корректно подписать и проверить без Xcode и соответствующей команды разработчика.
