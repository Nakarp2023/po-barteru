# ПО БАРТЕРУ — план аудита и доведения до готового продукта

**Статус:** рабочая дорожная карта. Выполнять строго по порядку, пункт за пунктом.
**Рабочая ветка:** feat/stable-screen-navigation
**Production:** main и production-сервисы не менять без отдельного согласования.

## Правила работы
1. Идти последовательно по этапам; отмечать пункт выполненным только после проверки результата.
2. Сначала диагностика, затем изменение, затем проверка на Preview/Staging.
3. Не менять реальные платежные статусы, пользовательские записи, активные сделки и данные Production в ходе аудита.
4. Не выполнять миграции на Production и не менять секреты/платёжные настройки без отдельной проверки и согласования.
5. Сохранять утверждённый дизайн главной страницы; не переделывать его без необходимости.
6. Не отключать все жесты подряд: локальные жесты галереи, удаления уведомлений и другие полезные действия должны сохраняться.
7. Юридические документы и правовые вопросы отложены до отдельного этапа по решению владельца проекта.
